Install

Ready in a minute.

  1. Download one file, about 20 MB.
  2. Drag Muhurta Pomodoro into Applications.
  3. Open it once via System Settings → Privacy & Security → Open Anyway.
Why does my Mac ask?

Apple charges developers $99 a year to register an app. This is a free project, so macOS asks you to confirm it the first time. After that it opens like any other app.

Questions

Is it really free?

Yes. No trial, no subscription, no ads. It was made for friends and is shared as it is.

Does it need the internet?

Only to sign in the first time. After that everything works offline, and changes sync when you're back online.

What happens to my data?

Your sessions, combinations and settings go to your own account, with a copy on each computer you're signed in on. Besides that the app only sends its version number, so updates reach everyone. Nothing is sold or shared. Signing out saves everything and removes it from that computer.

Which Macs?

Apple Silicon Macs (M1 and newer, late 2020 onwards). Intel Macs aren't supported yet.

How do updates work?

A notice appears in the app. Click Update now; it reopens on the new version and shows what changed.

Windows? Android?

A Windows version is available. Android is planned.
